# replay

## Sub-features
- `shape replay <file.json>` replays a saved `{saga, invariant, seed, realized}` file, prints the full trace, then `VIOLATION <invariant>: <message>` lines; exit 1 if any violation, 0 otherwise.

## How to get to it (user POV)
`shape replay runs/seed-24.at_most_once_effect.min.json` (README).

## Driving it with verify.sh
Run `run-toy` first (it produces the file), then `verify.sh replay`. It replays the first `run-toy/*.min.json` and asserts exit 1 and `VIOLATION at_most_once_effect` in `replay.out`: the same failure the run reported.

## Gotchas
- Depends on `run-toy` having written a file in the same evidence dir; it says so if none exists.
- Replay of a `fixed`-saga file would exit 0; none is generated by the harness.
